## Streaming a file

Pass `streaming: true` to play a remote file the way a file preview needs it: the `<audio>` element loads the URL itself, so playback starts before the download finishes and a cross-origin URL without CORS headers still plays. Load and playback failures arrive as `error`; passing it to `AudioPlayer` disables the controls. `filename` names the file that `download()` saves; browsers ignore it for cross-origin URLs and open the file in a new tab instead, so pass your own `download` to `AudioPlayer` when you need a real download there.
